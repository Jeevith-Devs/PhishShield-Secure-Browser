# PhishShield Secure Dedicated Browser

## Overview
The dedicated PhishShield browser is a hardened Chromium/Electron-based environment designed for incident responders and security analysts.

## Key Capabilities
- Native integration with the PhishShield Risk Scoring Engine.
- Ephemeral session profiles: zero local cookie caching across origins.
- In-browser threat indicator bar displaying live risk scores and domain infrastructure data.
- Built-in controlled sandbox trigger with synthetic identity injection.
